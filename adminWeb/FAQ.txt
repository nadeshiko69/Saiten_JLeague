
●立ち上げ
    ・仮想環境の作成
    　642  python3 -m venv django-venv
    ・仮想環境に入る
    　643  cd django-venv
    　645  source bin/activate
    ・仮想環境内にDjangoをインストール、freezeで確認
    　※競合しないように仮想環境ごとに使うフレームワークを分けてinstallする
    　646  python3 -m pip install django
    　648  pip freeze
    ・プロジェクトフォルダ作成
　    685  django-admin startproject pJudgeOperator
    ・アプリケーション作成
　    687  cd pJudgeOperator
  　  688  python manage.py startapp aFirebaseOperator

    <構成>
    django-venv
     L bin
     L include
     L lib
     L pJudgeOperator           # Project
        L aFirebaseOperator     # App
        L pJudgeOperator
        L manage.py
    
    ・Server起動してみる
    上記のpJudgeOperatorフォルダをCodeで開き直す（# Projectって書いてある方）
    source ../bin/activate で仮想環境に入る
    あとは基本的には参考欄のQiitaを見る
    
    ※ VScodeで仮想環境内のPythonが指定できていないとエラーになるよ
    - `python manage.py runserver`を手打ちすると起動できるけど、
      F5でcodeに起動してもらおうとするとDjangoが入ってない的なことを言われる
    - 仮想環境に入った状態で`which python`で仮想環境ないのPythonパスを調べてコピー
      View->Command Parette->Select Interpriter->インタプリタパスを入力からコピーしたパスをペーストする
