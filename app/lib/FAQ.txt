

* Null Checkについて
?を要素の後ろにつけると、その要素が値を取得出来なかった場合もNULLとして処理を続行する
=値が入っていなくてもエラーにならずに続行できる


* Winで作業後MacでPullしてBuildでエラー発生
エラーメッセージ
    error running pod install Error launching application on iPhone 13.
解決方法
    Podfile.lockを削除して再インストール、クリーン
    ios/podfile.lockを削除
    iosディレクトリで　pod install --repo-update
    flutter clean

    詳細は　https://dolphinetech.com/flutter/error-running-pod-install/
    https://minpro.net/error-running-pod-install

    プラグインのバージョンが古いのが原因かも
    https://minpro.net/requested-but-did-not-find-extension-point-with-identifier-xcode

    ARM64のSimulatorを除外してみる
    https://qiita.com/littleossa/items/ff75b19e0ac6713941f8
    →　下記Errorは発生
    Swift Compiler Error (Xcode): Could not find module 'Stripe' for target 'arm64-apple-ios-simulator'; found: x86_64-apple-ios-simulator, at:

* Androidフォルダ内のMainActivity.ktがデフォルトで赤字になっている
* Unresolved reference: FlutterFragmentActivity
    ファイルを開いた時のPathの問題
    Androidフォルダを選択した状態でFile -> Openからファイルを開くとOK
